# theoros-delivery requirements

| ID | Requirement | Verification |
|---|---|---|
| DEL-REQ-001 | A package shall be rejected on board if its signature or any checksum fails. | Test |
| DEL-REQ-002 | A package shall record the sensor fingerprint it was compiled for. | Inspection |
| DEL-REQ-003 | An uplink shall resume after an interrupted pass without retransmitting completed chunks. | Test |
| DEL-REQ-004 | The previous model shall remain available until the new model passes its self-test. | Test |

Status: baseline, November 2026. Changes need approval from the CTO.
